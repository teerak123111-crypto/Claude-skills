สวัสดีค่ะโชริน นี่คือคลิปทบทวน เรื่องการอ่านสเปคอุปกรณ์ ฟังสบาย ๆ ไม่ต้องจดนะคะ
#
หลักการข้อแรก สเปคยาวแค่ไหนก็ไม่ต้องตกใจ ให้แบ่งบรรทัดเป็นสามกลุ่ม
กลุ่มที่หนึ่ง บรรทัดที่บอกชนิดของอุปกรณ์ อันนี้สำคัญที่สุด ให้หาก่อน
กลุ่มที่สอง ตัวเลขคุณภาพ เช่น เฮิรตซ์ โอห์ม เดซิเบล ไม่ต้องจำตัวเลข ดูแค่ว่าสูงหรือต่ำ
กลุ่มที่สาม ข้อมูลทั่วไป เช่น สี วัสดุสาย ความยาวสาย ข้ามได้เลย ยกเว้นขนาดกับน้ำหนัก ที่ช่วยบอกรูปทรงของอุปกรณ์
#
ขั้นต่อไป ดูหน่วยในสเปค ก็แยกกลุ่มอุปกรณ์ได้ทันที
ถ้าเห็นเฮิรตซ์ โอห์ม เดซิเบล หรือโพลาร์แพทเทิร์น คืออุปกรณ์เสียง
ถ้าเห็นความละเอียดจอ รีเฟรชเรต มิลลิวินาที หรือนิต คือจอภาพ
ถ้าเห็นเซนเซอร์ เมกะพิกเซล ไอเอสโอ คือกล้อง
ถ้าเห็นมิลลิเมตร กับเอฟสต็อป คือเลนส์
ถ้าเห็นเคลวิน ซีอาร์ไอ หรือลักซ์ คือไฟถ่ายทำ
#
มาที่ไมโครโฟน
ถ้าเห็นคำว่า แฟนทอมพาวเวอร์ บวกสี่สิบแปดโวลต์ หรือคำว่า คอนเดนเซอร์ แคปซูล คือไมค์คอนเดนเซอร์ รับเสียงไว ละเอียด ใช้อัดเสียงในสตูดิโอ
ถ้าแคปซูลขนาดหนึ่งนิ้ว คือคอนเดนเซอร์ไดอะแฟรมใหญ่ ถ้าครึ่งนิ้ว ทรงแท่งดินสอ คือไดอะแฟรมเล็ก ใช้อัดเครื่องดนตรี
ถ้าเห็นคำว่า ไดนามิก หรือ มูฟวิ่งคอยล์ ไม่ต้องใช้ไฟ ทนทาน คือไมค์ไดนามิก ใช้บนเวที
ทริคสำคัญ ดูความไว หรือเซนซิทิวิตี้ ถ้าประมาณยี่สิบห้ามิลลิโวลต์ ไวมาก คือคอนเดนเซอร์ ถ้าประมาณสองมิลลิโวลต์ ไวน้อย คือไดนามิก
ถ้าเห็นริบบอน กับฟิกเกอร์เอท คือไมค์ริบบอน เสียงนุ่ม บอบบาง
ถ้าเห็นทรานสมิตเตอร์ รีซีฟเวอร์ คลื่นยูเอชเอฟ ระยะทาง และแบตเตอรี่ คือไมค์ไร้สาย
ถ้าเห็นออมนิ ขนาดเล็กมาก มีคลิปหนีบ คือไมค์หนีบปก หรือลาวาเลียร์
ถ้าเห็นซูเปอร์คาร์ดิออยด์ หรือโลบาร์ ตัวยาวยี่สิบถึงสามสิบเซนติเมตร คือไมค์ช็อตกัน ใช้ถ่ายหนัง
ถ้าเห็นยูเอสบีซี กับยี่สิบสี่บิต สี่สิบแปดกิโลเฮิรตซ์ เสียบคอมได้เลย คือไมค์ยูเอสบี
#
รูปแบบการรับเสียง หรือโพลาร์แพทเทิร์น
คาร์ดิออยด์ รูปหัวใจ รับด้านหน้า ตัดด้านหลัง เจอบ่อยที่สุด
ออมนิ รับรอบทิศ
ฟิกเกอร์เอท รับหน้าและหลัง ตัดด้านข้าง
โลบาร์ รับแคบมาก เหมือนไฟฉาย
#
มาที่หูฟัง
ถ้าเห็นโอเพ่น หรือโอเพ่นแบ็ก แปลว่าฝาเปิด เสียงโปร่ง แต่เสียงรั่ว ใช้มิกซ์ในห้องเงียบ
ถ้าเห็นโคลสแบ็ก แปลว่าฝาปิด กันเสียง ใช้ตอนอัดเสียง
ถ้าเห็นเอียร์มัฟ เอียร์แพด เฮดแบนด์ หรือแรงบีบหัว คือหูฟังครอบหู
ถ้าเห็นเอียร์ทิป หรือจุกขนาดเอส เอ็ม แอล คือหูฟังจุก
ถ้าเห็นกล่องชาร์จ คือหูฟังไร้สายแยกสองข้าง หรือทีดับเบิลยูเอส
ถ้าเห็นโบนคอนดักชัน คือหูฟังที่ส่งเสียงผ่านกระดูก ไม่อุดหู
ถ้าเห็นบลูทูธ แบตเตอรี่ หรือเอเอ็นซี คือหูฟังไร้สาย มีระบบตัดเสียงรบกวน
ขนาดไดรเวอร์ก็ช่วยได้ สี่สิบถึงห้าสิบมิลลิเมตร คือหูฟังครอบหู หกถึงสิบสี่มิลลิเมตร คือหูฟังจุกหรือเอียร์บัด
คำว่าอิมพีแดนซ์ บางร้านเขียนว่าเรซิสแตนซ์ คือความต้านทาน ถ้าสิบหกถึงสามสิบสองโอห์ม ใช้กับมือถือได้ ถ้าแปดสิบถึงสามร้อยโอห์ม ต้องใช้แอมป์
ระวังคำว่าไดนามิก ในไมค์ แปลว่าไมค์ไดนามิก แต่ในหูฟัง แปลว่าชนิดของไดรเวอร์ทั่วไป
#
มาที่ลำโพง
ถ้าเห็นวูฟเฟอร์ กับทวีตเตอร์ คือลำโพง วูฟเฟอร์เสียงต่ำ ทวีตเตอร์เสียงแหลม
ถ้ามีไบแอมป์ หรือมีแอมป์ในตัว คือลำโพงแอคทีฟ ถ้าต้องต่อแอมป์แยก คือพาสซีฟ
ถ้าเห็นแฟลตเรสพอนส์ คือลำโพงมอนิเตอร์สตูดิโอ เสียงตรง ใช้มิกซ์
ถ้ากำลังขับเป็นพันวัตต์ ดอกสิบห้านิ้ว ดังมาก คือลำโพงพีเอ ใช้งานเวที
ถ้าเล่นแค่ความถี่ต่ำ ดอกใหญ่สิบแปดนิ้ว คือซับวูฟเฟอร์
#
มาที่มิกเซอร์และอินเตอร์เฟซ
ถ้าเห็นจำนวนแชนแนล อีคิว ออกซ์เซนด์ และเฟดเดอร์ คือมิกเซอร์ ใช้ผสมเสียงหลายช่อง
ถ้ามีจอสัมผัส บันทึกค่าซีนได้ คือดิจิทัลมิกเซอร์
ถ้ามีแค่สองช่อง ยี่สิบสี่บิต หนึ่งร้อยเก้าสิบสองกิโลเฮิรตซ์ ต่อยูเอสบีเข้าคอม คือออดิโออินเตอร์เฟซ
#
มาลองอ่านสเปคจริงกัน ตัวแรก ชัวร์ เคเอสเอ็มแปด
สเปคบอกว่า ดูอัลไดอะแฟรม ไดนามิก มูฟวิ่งคอยล์ ความไวหนึ่งจุดแปดห้ามิลลิโวลต์ ตัวถังอะลูมิเนียม ต่อสายเอกซ์แอลอาร์
แปลว่า เป็นไมค์ไดนามิกแบบถือ มีสาย ทนทาน เก็บเสียงรบกวนน้อย เหมาะกับร้องเพลงบนเวที
#
ตัวที่สอง ไมค์ที่มีหนึ่งนิ้วคอนเดนเซอร์แคปซูล คาร์ดิออยด์ ไซด์แอดเดรส ความไวยี่สิบห้ามิลลิโวลต์ และมีทั้งเอกซ์แอลอาร์และยูเอสบีซี
แปลว่า เป็นไมค์คอนเดนเซอร์ไดอะแฟรมใหญ่ แบบไฮบริด พูดเข้าด้านข้าง เหมาะกับพากย์เสียงและพอดแคสต์
#
ตัวที่สาม เจบีแอล จูนเจ็ดเจ็ดศูนย์เอ็นซี
เอ็นซี คือตัดเสียงรบกวน มีบลูทูธ แบตเจ็ดสิบชั่วโมง สามสิบสองโอห์ม ขนาดประมาณยี่สิบเซนติเมตร
แปลว่า เป็นหูฟังไร้สายแบบครอบหู มีระบบตัดเสียงรบกวน ใช้ฟังเพลงและคุยโทรศัพท์
#
ตัวที่สี่ เอฟทีวันโปร
สเปคบอกว่า โอเพ่นแฟลตเฮดโฟน ไดรเวอร์แผ่นใหญ่เก้าสิบห้าคูณแปดสิบหกมิลลิเมตร หนักสามร้อยเจ็ดสิบสี่กรัม มีแรงบีบของเอียร์มัฟ และถอดสายได้
แปลว่า เป็นหูฟังครอบหูแบบฝาเปิด ไดรเวอร์แบบแผ่นแบน หรือแพลนาร์ ชนิดมีสาย เหมาะกับฟังเพลงละเอียดในห้องเงียบ
#
สุดท้าย สูตรเขียนตอบ จำไว้สี่ส่วน
หนึ่ง บอกว่าอุปกรณ์นี้คืออะไร ชนิดไหน
สอง เพราะสเปคบรรทัดไหนบอก
สาม บรรทัดนั้นแปลว่าอะไร
สี่ เหมาะกับงานอะไร
#
ลองทายดูนะคะ ถ้าเห็นแฟนทอมพาวเวอร์ บวกสี่สิบแปดโวลต์ คืออะไร
เฉลย ไมค์คอนเดนเซอร์
ถ้าเห็นโอเพ่นแบ็ก ฝาเปิด คืออะไร
เฉลย หูฟังครอบหูแบบฝาเปิด ใช้มิกซ์ในห้องเงียบ
ถ้าเห็นวูฟเฟอร์ ทวีตเตอร์ และไบแอมป์ คืออะไร
เฉลย ลำโพงมอนิเตอร์แบบแอคทีฟ
