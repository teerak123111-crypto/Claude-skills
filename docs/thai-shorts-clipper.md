# สกิลตัดคลิปสั้น `thai-shorts-clipper`

ใส่วิดีโอยาว 1 คลิป แล้วได้คลิปสั้นแนวตั้ง 9:16 หลายคลิป พร้อมซับไทย สำหรับ TikTok, Reels และ Shorts
ไฟล์สกิลอยู่ที่ `.claude/skills/thai-shorts-clipper/`

## มีอะไรบ้าง

| ฟีเจอร์ | ทำงานอย่างไร |
|---|---|
| หาช่วงเด็ด | Whisper ถอดเสียง แล้ว Claude อ่านทั้งเรื่องเพื่อเลือกช่วงที่มีฮุก จบในตัว และมีจุดพีค |
| ซับไทยอัตโนมัติ | ตัดคำด้วย PyThaiNLP ให้ซับขึ้นทีละคำตามเสียงพูด คำสำคัญเป็นสีเหลือง มี 3 โหมดคือ `build`, `karaoke` และ `line` |
| แก้ซับ | แก้ข้อความในไฟล์ `<id>.subs.json` แล้ว render ใหม่ เวลาของซับจะปรับตามเอง |
| AI Hook | Claude เขียนพาดหัวด้านบนจอ และเสนอให้เลือก 2 แบบ |
| ตามคนพูด | ตรวจจับใบหน้าแล้วดูว่าปากใครขยับ จากนั้นเลื่อนกรอบ 9:16 ไปหาคนนั้น |
| เลย์เอาต์ | `full` เต็มจอ / `split` แบ่งครึ่งบนล่าง / `fit` ใส่กรอบบนพื้นหลังเบลอ |
| ซูมอัตโนมัติ | ซูมเข้าเบาๆ ตอนพูดคำสำคัญ แล้วค่อยๆ ถอยออก |
| B-roll | แทรกรูปหรือวิดีโอที่**เราเตรียมเอง** (สกิลนี้ไม่สร้าง B-roll ให้) |
| ไฟล์ที่ได้ | `.mp4` ขนาด 1080×1920, ไฟล์ซับ `.srt` และตารางสรุป `clips.md` |

## ติดตั้ง (ครั้งเดียว)

1. ติดตั้ง FFmpeg ก่อน: macOS ใช้ `brew install ffmpeg` ส่วน Windows ใช้ `winget install Gyan.FFmpeg`
2. รันคำสั่ง `pip install -r .claude/skills/thai-shorts-clipper/requirements.txt`
3. (แนะนำ) ดาวน์โหลดฟอนต์ **Kanit** หรือ **Prompt** จาก Google Fonts มาใส่ในโฟลเดอร์ `fonts/` ซับจะได้ตัวหนาแบบคลิปสั้น

## ใช้งาน

เปิด Claude Code ในโฟลเดอร์ repo นี้ แล้วพิมพ์ เช่น

```
ตัดคลิปสั้นจาก /path/to/vlog.mp4 ให้หน่อย ขอ 5 คลิป ลง TikTok
```

Claude จะทำงานตามลำดับนี้

1. ถอดเสียง
2. เสนอตารางคลิป พร้อมช่วงเวลา ฮุก และเหตุผล ให้เราเลือกหรือแก้ก่อน
3. render ตัวอย่าง 1 คลิป
4. render คลิปทั้งหมด

## ข้อจำกัดที่ควรรู้

- ถ้าเครื่องไม่มีการ์ดจอ การถอดเสียงด้วยโมเดล `large-v3` จะช้า อาจนานพอๆ กับความยาวของวิดีโอ ถ้าอยากลองเร็วๆ ใช้โมเดล `medium` ได้ แต่จะแม่นน้อยลง
- Whisper ถอดชื่อเฉพาะ คำสแลง และคำอังกฤษผิดได้ ควรอ่านซับทวนก่อนโพสต์ทุกครั้ง
- การดูว่าใครกำลังพูดใช้วิธีดูปากขยับ จึงอาจจับผิดคนได้ ถ้าคนที่ฟังอยู่ขยับปากหรือหน้าบ่อย ให้เปลี่ยนเป็น `split` หรือ `fit`
- ตัดได้เฉพาะวิดีโอที่เราเป็นเจ้าของหรือได้รับสิทธิ์แล้ว
