# vox-style-documentary — สกิล Claude ทำคลิปสารคดีสไตล์ Vox

สกิลสำหรับ Claude Code ใช้ทำคลิปสารคดี ประวัติศาสตร์ หรือคดีปริศนาจากเสียงพากย์ภาษาไทย
ได้ทั้ง **แนวตั้ง 9:16** (TikTok / Reels / Shorts) และ **แนวนอน 16:9** (YouTube) Claude จะถามก่อนทุกครั้งว่าจะเอาแบบไหน

Claude วางแผนช็อตและเขียน prompt ภาพให้เป็นใบงาน นักเรียนนำไปเจนภาพในเครื่องมือที่ใช้อยู่ (ChatGPT, Gemini ฯลฯ)
แล้วนำภาพกลับมา โปรแกรมจะตรวจภาพ ลบพื้นหลังตัวละคร และวางภาพเป็นชั้น (ฉากหลัง / ตัวละครไดคัท / ฉากหน้า)
แล้วโค้ดจะขยับกล้องให้ภาพดูมีมิติ พร้อมใส่คำสีแดงไว้หลังตัวละคร เกรนฟิล์ม กระดาษเก่า บอร์ดหลักฐาน และเพลงประกอบที่สร้างขึ้นเอง

ใช้กับ**คลิปนั่งพูดเห็นหน้า**ได้ด้วย โดยหน้าผู้พูดจะเป็นวงกลมเล็กตรงกลางด้านล่าง (ราว 60–90% ของคลิป) เต็มจอช่วงเปิดและปิด (ราว 10%)
และตัวละครในภาพใช้หน้าผู้พูดเองได้ ถ้าเรื่องเล่าถึงตัวเอง

ดูตัวอย่างผลลัพธ์ได้ที่ `example/db-cooper/animatic-9x16.jpg` และ `animatic-16x9.jpg`
(ในตัวอย่างใช้ภาพแทนชั่วคราว เพื่อให้เห็นจังหวะคลิปก่อนเจนภาพจริง)

## ต้องมีอะไรบ้าง
- **Claude Code** (แอป Claude บนเดสก์ท็อป แท็บ Code หรือใช้ผ่าน Terminal ก็ได้)
- โปรแกรมบนเครื่อง: ffmpeg, Node.js, Python 3 (ติดตั้งตาม `SETUP.md` ใช้เวลาประมาณ 10 นาที)
- เครื่องมือเจนภาพที่ใช้ได้อยู่แล้ว เช่น ChatGPT, Gemini, Midjourney, Leonardo (ไม่ต้องสมัครบริการ API)
- ลบพื้นหลังตัวละคร: บน Mac ทำให้อัตโนมัติฟรี (macOS 14 ขึ้นไป) บน Windows ใช้ remove.bg หรือ Canva แล้วบันทึกเป็น PNG

## ติดตั้งสกิล
**Mac**
```bash
mkdir -p ~/.claude/skills
unzip vox-style-documentary.zip -d ~/.claude/skills/
```
**Windows** (PowerShell)
```powershell
mkdir $HOME\.claude\skills -Force
Expand-Archive vox-style-documentary.zip -DestinationPath $HOME\.claude\skills\
```
จากนั้นทำตาม `SETUP.md` (ติดตั้ง ffmpeg / Node / Python / Playwright) แล้วปิดและเปิด Claude Code ใหม่

ตรวจว่าติดตั้งสำเร็จ: ใน Claude Code พิมพ์ว่า `/vox-style-documentary` หรือถามว่า "มีสกิลทำคลิปสไตล์ Vox ไหม"

## เริ่มใช้งาน
1. เตรียมบทพูดภาษาไทย และไฟล์เสียงพากย์หรือคลิปนั่งพูดที่อ่านบทนั้น (ถ้ายังไม่มีบท ให้ Claude เขียนให้ได้)
2. เปิด Claude Code ในโฟลเดอร์งาน แล้วพิมพ์ว่า **"ทำคลิปสไตล์ Vox จากเสียงนี้"** พร้อมแนบไฟล์เสียงและบท
3. ตอบคำถามแรกของ Claude: แนวตั้งหรือแนวนอน และเลือก "ส่ง prompt ให้ไปเจนเอง"
4. ดูภาพ animatic (ภาพแทนชั่วคราว) ที่ Claude ส่งมา เพื่อเช็กจังหวะคลิป
5. เปิดใบงาน `prompts.html` กดคัดลอก prompt ทีละภาพ ไปเจนภาพ แล้ว**ตั้งชื่อไฟล์ตามใบงาน** วางในโฟลเดอร์ `images`
   (ถ้ามีตัวละคร ให้เจนภาพอ้างอิงตัวละครก่อน แล้วแนบภาพนั้นทุกครั้ง หน้าตาจะได้เหมือนกันทุกช็อต)
6. บอก Claude ว่า "ใส่ภาพแล้ว" Claude จะตรวจภาพ ลบพื้นหลังตัวละคร และบอกว่าภาพไหนต้องแก้
7. ได้ไฟล์ `ชื่อคลิป (มีเพลง).mp4`, `ชื่อคลิป (ไม่มีเพลง).mp4` และ `ปก.jpg`

รายละเอียดการปรับแต่งเพิ่มเติมอยู่ใน `HOW-TO-USE.md`

## ข้อควรรู้
- ฟอนต์ IBM Plex Sans Thai แนบมาภายใต้สัญญาอนุญาต SIL Open Font License (`engine/fonts/OFL.txt`)
- ภาพที่เจนจาก AI และเสียงพากย์ ให้ตรวจเงื่อนไขการใช้งานของบริการที่ใช้ก่อนนำคลิปไปเผยแพร่
- ถ้าทำคลิปเรื่องจริงหรือบุคคลจริง ให้ตรวจข้อเท็จจริงและใส่แหล่งอ้างอิงในคำอธิบายคลิป
