# Reference: "How I Made This Vox-Style Animation in After Effects" (สไตล์ Vox สารคดีประวัติศาสตร์)

คลิปอ้างอิง (ไม่ได้แนบมา เพราะเป็นผลงานของผู้อื่น): 720x1280 **9:16 แนวตั้ง**, 25 fps, ยาว 31.9 วิ, -21 LUFS (LRA 2.1 LU)
ภาพตัวอย่างลุคที่เอนจินนี้ทำได้: `example/db-cooper/animatic-9x16.jpg` และ `animatic-16x9.jpg`

เรื่อง: นักต้มตุ๋น Victor Lustig "ขายหอไอเฟล" ปี 1925 เล่าแบบสารคดีปริศนา ปิดด้วยคลิฟแฮงเกอร์ "And the strangest part..."

## 1. ภาพรวมลุค
- **ไม่ใช่ภาพวาดเวกเตอร์** แต่เป็น "ภาพนิ่งเสมือนจริง (AI) ที่ถูกจัดองค์ประกอบแบบ 2.5D ใน After Effects"
  ทุกช็อตคือภาพนิ่ง 1–3 ชั้น (ฉากหลัง / ตัวละครที่ไดคัทแล้ว / ฉากหน้า) ที่กล้องเคลื่อนช้าๆ ให้เกิดพารัลแลกซ์
- โทน **ซีเปียอุ่น ฟิล์มเก่า**: ฉากกลางวันเป็นครีม-เบจ (#bda68e, #dbc7b4), ฉากในห้องเป็นน้ำตาลเข้ม-ไม้ (#362f2c, #2d2420)
  มีแสงส้มทองจากหน้าต่าง/โคมไฟ, แสงขอบ (rim light) และ god rays
- ทับทั้งเฟรมด้วย: **เกรนฟิล์ม** + **เท็กซ์เจอร์กระดาษเก่า** (เห็นชัดในฉากสว่าง) + **วิกเน็ตต์** + ฝุ่น/รอยขีด + หมอกลอย
- ฉากหลังสว่างจะ "ซีด" เหมือนพิมพ์บนกระดาษ ส่วนตัวละครคมชัดกว่า (แยกชั้นด้วยความคมและคอนทราสต์)

## 2. ตัวอักษร (kinetic typography)
- สีหลัก **แดงเข้ม Vox** (~#c8232f) ใช้กับคำสำคัญเท่านั้น ไม่มีซับเต็มประโยค
- ผสม 2 ฟอนต์ในคำเดียวกัน: **serif ตัวเอียงหนา** (ชื่อคน, "DEAL", "REAL") + **sans หนาตัวตรง** ("IN 1925", "WAS", "DISAPPEARED")
- ข้อความ **อยู่หลังตัวละคร** ได้ (ตัวเลข 1925 อยู่หลังหอไอเฟล, DEAL WAS REAL อยู่หลังคนจับมือ) = วางเป็นชั้นระหว่างฉากหลังกับตัวละคร
- ข้อความเผยทีละคำ: เบลอ+จาง → คมชัด (ไม่เด้งแบบการ์ตูน), มีหมอกพัดผ่านตัวอักษร, ตัวอักษรมีเนื้อสีไม่เรียบเหมือนพิมพ์บนกระดาษ
- การ์ดกระดาษน้ำตาล (#9f7c5e) + ตัวขาว sans บางกลางจอ ใช้เป็นประโยคเชื่อม/คลิฟแฮงเกอร์ ("And the strangest part")

## 3. การเคลื่อนกล้อง (ไม่เคยนิ่ง)
- 0–4 วิ: กล้อง tilt ลงผ่านเมฆหมอก เผยหอไอเฟล, ตัวละคร "โตขึ้น" จากหลังหอ (ชั้นไดคัท scale-up), พุ่มไม้ฉากหน้าเลื่อนเข้ามา
- push-in ช้าต่อเนื่องเกือบทุกช็อต (~5–10% ต่อ 4 วิ), บางช็อต pull-out เผยห้อง
- พารัลแลกซ์: ฉากหลังเลื่อนช้ากว่าตัวละคร, ฉากหน้า (พุ่มไม้, ไหล่คนเบลอ) เลื่อนเร็วกว่า
- โฟกัส: บางช็อตเบลอฉากหน้าเป็นชั้นหน้าสุด (over-the-shoulder) แล้ว rack focus

## 4. ทรานสิชัน
- **whip pan** แนวนอน + motion blur (หอไอเฟล → แกลเลอรี ~3.8 วิ)
- **zoom-through**: ซูมเข้ากรอบรูปจนภาพในกรอบกลายเป็นฉากใหม่ (5–7 วิ)
- **defocus dip**: เบลอ + มืดลงจนเกือบดำ แล้วเปิดฉากใหม่จากเบลอ → คม (18.5–19.5 วิ)
- **blur cross-dissolve** ระหว่างช็อตในเรื่องเดียวกัน
- cut ตรงๆ ตอนเข้าการ์ดกระดาษ (เปลี่ยนจังหวะ)

## 5. กราฟิกเสริม
- บอร์ดไม้ก๊อก + เอกสารเก่า + ภาพถ่ายขาวดำขอบขาว + คลิปหนีบ + ตราประทับแดง (CONFIDENTIEL, TOP SECRET)
- **ปากกาแดงวาดวง** บนเอกสารแบบมือวาด (stroke ค่อยๆ วิ่ง วนเกิน มีหางพุ่งออก)
- กรอบรูปทองในแกลเลอรี, โคมไฟห้อยแสงลง

## 6. จังหวะ
- 31.9 วิ มี ~10 ช็อต (เฉลี่ย 3–4 วิ/ช็อต) แต่ภาพไม่เคยนิ่ง
- คำแดงขึ้นตรงกับคำพากย์สำคัญ (ปี, ชื่อ, คำหักมุม)
- เสียง: พากย์ผู้ชายแบบสารคดีลึกลับ + ดนตรีตึงเครียด (โดรนต่ำ, เปียโน, พัลส์) + whoosh ตอนทรานสิชัน, hit ตอนคำสำคัญ

## 7. แปลเป็นเอนจิน (สิ่งที่ skill นี้ทำ)
| องค์ประกอบในต้นฉบับ | ในเอนจิน |
|---|---|
| ภาพนิ่ง AI ฉากหลัง | `plate()` + ภาพจาก AI (หรือภาพที่ผู้ใช้ให้) |
| ตัวละครไดคัท | `cut()` (PNG โปร่งใส จากโมเดลลบพื้นหลัง) |
| กล้อง 2.5D พารัลแลกซ์ | `camera()` + ความลึก `d` ของแต่ละชั้น |
| คำแดง serif/sans หลังตัวละคร | `words()` วาดก่อน `cut()` |
| เกรน กระดาษ ฝุ่น หมอก วิกเน็ตต์ เกรดสี | `LOOK` + `fog()` `leak()` `rays()` |
| ปากกาแดง ตราประทับ เอกสาร รูปถ่าย หมุด เชือกแดง | `marker*()` `stamp()` `doc()` `photo()` `pin()` `string()` |
| whip / zoom-through / defocus dip / blur dissolve | `TR`: `whip` `zoom` `dip` `blur` `fade` `cut` `push` `burn` |
| ภาพในกรอบ → ฉากใหม่ | `zoom` ทรานสิชันที่จุด `at` |
