# สกิล: คลิปสารคดีสไตล์ Vox (ภาพถ่ายจัดเลเยอร์ 2.5D)

ทำคลิปสารคดี/ประวัติศาสตร์/คดีปริศนาจากเสียงพากย์ภาษาไทย ได้ทั้ง **แนวตั้ง 9:16** และ **แนวนอน 16:9** (Claude จะถามก่อนทุกครั้ง)
ภาพแต่ละช็อตเป็นภาพนิ่งเสมือนจริงจาก AI (หรือภาพของคุณเอง) วางเป็นชั้น ฉากหลัง / ตัวละครไดคัท / ฉากหน้า แล้วโค้ดขยับกล้องให้มีมิติ
ใส่คำสีแดงไว้หลังตัวละคร เกรนฟิล์ม กระดาษเก่า หมอก แสงลอด บอร์ดหลักฐาน ปากกาแดงวง ตราประทับ และทรานสิชันแบบ After Effects

ตัวอย่าง: "ชายที่หายไปกลางฟ้า" (D.B. Cooper 1971) ในโฟลเดอร์ `example/db-cooper` (บท, ใบงาน prompt ภาพ `prompts.html`, episode.js, ภาพ animatic)

## ได้อะไรออกมา
- `ชื่อคลิป (มีเพลง).mp4` และ `ชื่อคลิป (ไม่มีเพลง).mp4` ขนาด 1080x1920 หรือ 1920x1080, 30fps, ดัง -14 LUFS
- `ปก.jpg` ขนาดเดียวกับคลิป
- เพลงประกอบแนวสารคดีลึกลับและเสียงประกอบสร้างเองทั้งหมด ไม่ติดลิขสิทธิ์

## ขั้นตอนเมื่อสั่ง Claude
พิมพ์ว่า "ทำคลิปสไตล์ Vox จากเสียงนี้" แล้วแนบไฟล์เสียงกับบท Claude จะ
1. **ถามก่อน** ว่าเอาแนวตั้งหรือแนวนอน และจะทำภาพแบบไหน (ค่าเริ่มต้น: Claude ส่ง prompt ให้คุณไปเจนเอง)
2. ตัดช่วงเงียบ จับเวลาแต่ละวลีจากบท
3. วางแผนช็อต (ราว 14 ช็อตต่อนาที) แล้วเรนเดอร์ **animatic** (ภาพแทนชั่วคราว) ให้ดูจังหวะก่อน
4. ส่ง **ใบงานภาพ** `prompts.html` ให้ ทุกภาพมีปุ่มคัดลอก prompt, ชื่อไฟล์ที่ต้องบันทึก, สัดส่วน และขนาด
5. คุณนำ prompt ไปเจนในเครื่องมือที่มี (ChatGPT, Gemini, Midjourney, Leonardo ฯลฯ) ตั้งชื่อไฟล์ตามใบงาน วางในโฟลเดอร์ `images`
6. บอก Claude ว่า "ใส่ภาพแล้ว" ระบบจะตรวจชื่อ ขนาด แนวภาพ และลบพื้นหลังตัวละครให้อัตโนมัติ (บน Mac) แล้วแจ้งว่าภาพไหนต้องแก้
7. เรนเดอร์คลิปจริง + เพลง/เสียงประกอบ + ปก

## คลิปนั่งพูดเห็นหน้า
ถ้าส่งคลิปที่คุณพูดหน้ากล้องมาแทนไฟล์เสียง:
- หน้าคุณจะเป็น**วงกลมเล็กตรงกลางด้านล่าง** ราว 60–90% ของคลิป โดยมีกราฟิก Vox เล่นอยู่ด้านหลัง
- **เต็มจอ** ราว 10% ของคลิป (ช่วงเปิดเรื่องและตอนจบ)
- ที่เหลือเป็นกราฟิกล้วน เช่น การ์ดกระดาษ บอร์ดหลักฐาน หรือช่วงเฉลย
- หน้าผู้พูดใช้สีจริงของคลิป ไม่เกรดสี (เกรดเฉพาะกราฟิกด้านหลัง) ถ้าอยากให้เกรดด้วย ใส่ `SPKGRADE = true` ใน episode.js
- เสียงใช้จากคลิปเดิม ปากตรงกับเสียง (ไม่ตัดช่วงเงียบ)
- ระบบดึงภาพหน้าคุณที่ชัดที่สุดจากคลิปให้เป็น `images/speaker_ref.jpg`

## หน้าคนในภาพ
- เล่าเรื่องตัวเอง → ตัวละครใช้หน้าคุณ (แนบ `speaker_ref.jpg` ตอนเจนภาพ)
- เล่าถึงบุคคลจริงคนอื่น → หาภาพถ่ายหน้าตรงของคนนั้นที่มีสิทธิ์ใช้ บันทึกเป็นชื่อตามใบงาน แล้วแนบตอนเจนภาพ
- คนอื่น สถานที่ และสิ่งของอื่นๆ → Claude เขียน prompt ไว้ในใบงานให้คุณไปเจนเอง

## สิ่งที่ต้องเตรียม
1. บทพูด (ไม่มี บอกหัวข้อ Claude เขียนให้พร้อมแหล่งอ้างอิง)
2. ไฟล์เสียงพากย์ (เช่น ElevenLabs) **หรือคลิปนั่งพูดเห็นหน้า** และข้อความบทที่ใช้พูดจริง
3. หัวข้อปก (ไม่บอก Claude คิดให้)
4. เครื่องมือเจนภาพที่คุณใช้ได้อยู่แล้ว (ฟรีหรือเสียเงินก็ได้) หรือภาพของคุณเอง

## รันเองบนเครื่อง (หลังติดตั้งตาม SETUP.md)
```bash
S=~/.claude/skills/vox-style-documentary
W=~/Desktop/edit-video/งานใหม่
mkdir -p "$W" && cp -r "$S/engine" "$W/" && cd "$W"        # ใส่ vo.mp3 กับ script.txt ลงใน $W
#  แก้ engine/format.js เป็น '9:16' หรือ '16:9'
python3 "$S/tools/tighten.py" vo.mp3 vo-tight.wav 0.35 1.04 0.4
python3 "$S/tools/align.py" script.txt vo-tight-chunks.json words.json
#  >>> เขียน/แก้ engine/episode.js (ฉาก + รายการภาพพร้อม prompt ใน ASSETS) <<<
node "$S/tools/render.js" engine prompts .                  # สร้างใบงานภาพ prompts.html + โฟลเดอร์ images
#  >>> เจนภาพตามใบงาน ตั้งชื่อตามใบงาน วางใน images/ <<<
python3 "$S/tools/check_images.py" .                        # ตรวจ/ไดคัท/ย้ายเข้า engine/assets แล้วอัปเดตใบงาน
node "$S/tools/render.js" engine snap snaps 1,4,7,10,13     # ภาพตัวอย่าง
python3 "$S/tools/sheet.py" snaps sheet.jpg 6
node "$S/tools/render.js" engine info                       # ดูว่ายังขาดภาพไหน
bash "$S/tools/render_all.sh" . 4 30
bash "$S/tools/finish.sh" . "ชื่อคลิป"
```
ลองตัวอย่างแนวนอนโดยไม่ต้องแก้ไฟล์: `FMT=16:9 node "$S/tools/render.js" engine snap snaps 2,6,11`

## แก้บ่อย (engine/episode.js)
| อยากเปลี่ยน | แก้ที่ |
|---|---|
| แนวตั้ง/แนวนอน | `engine/format.js` |
| ภาพและ prompt ของแต่ละช็อต | `ASSETS` (`prompt`, `note`, `cut: true` = ไดคัท, `char` = ตัวละคร) แล้วสร้างใบงานใหม่ |
| สไตล์ภาพทั้งเรื่อง / ตัวละคร | `STYLE` (คำนำหน้าทุก prompt), `CHARS` (คำบรรยายตัวละคร) |
| ช็อตไหนอยู่ช่วงไหน | `SC` (เวลาเริ่ม, เวลาจบ, ชื่อฉาก, โทนพิเศษ) |
| ทรานสิชัน | `TR` (เวลา, แบบ: whip / zoom / dip / blur / fade / burn / push / flash / cut, ความยาว) |
| คำสีแดง | `words(t, [['คำ', เวลา, 'sans' หรือ 'serifI']], {...})` วางก่อน `cut()` = อยู่หลังตัวละคร |
| กล้อง | `camMove(t, เริ่ม, จบ, [x, y, ซูม], [x, y, ซูม])` |
| โทนภาพ | `LOOK` (grade: warm / sepia / noir / cold, grain, paper, dust, vignette) |
| เพลง/เสียง | `CUES.music` (intro mystery tension noir drive reveal sad hush outro), `CUES.sfx` |
| ปก | ฟังก์ชัน `cover()` |
